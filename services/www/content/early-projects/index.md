This page is an archive. Between 2016 and 2017 I was teaching myself front-end
development through freeCodeCamp, and `gatezh.com` was a portfolio of the
practice projects that came out of it. The site has been a blog for years now,
and the portfolio came down with the move — this restores it, more or less as
it read at the time.

The original described me as a "100% self-taught Front-end Developer" working in
HTML, CSS, JavaScript, Angular, npm, Python, Gulp, Sass, Bootstrap, git, Ubuntu
and bash. Four projects were on it. The source for all of them is in
[gatezh/FreeCodeCamp](https://github.com/gatezh/FreeCodeCamp), and each still
has a live CodePen demo.

## JavaScript Calculator

{{< cfimage src="images/javascript-calculator.png" alt="A JavaScript calculator with a numeric keypad and a display showing a running calculation" caption="JavaScript Calculator" >}}

A fully functional calculator built with JavaScript. It adds, subtracts,
multiplies and divides two numbers, clears the input field with a clear button,
and keeps chaining operations together until the equals button is pressed.

[Open the demo](https://codepen.io/gatezh/full/BRQdqB)

## Pomodoro Clock

{{< cfimage src="images/pomodoro-clock.png" alt="A Pomodoro timer showing a countdown with a circular progress bar and controls for work and break length" caption="Pomodoro Clock" >}}

A clock for the [Pomodoro technique](https://en.wikipedia.org/wiki/Pomodoro_Technique).
It allows a custom length for work and break time, and visualises elapsed time
with a progress bar. Built without any external CSS — Bootstrap only.

[Open the demo](https://codepen.io/gatezh/full/aWWgMM)

## Tic Tac Toe Game

{{< cfimage src="images/tic-tac-toe.png" alt="A Tic Tac Toe board with X and O markers placed across the grid" caption="Tic Tac Toe Game" >}}

A classic implementation of Tic Tac Toe. You play against an AI that knows every
possible combination, so you can only lose or — at best — draw.

[Open the demo](https://codepen.io/gatezh/full/MmERVQ)

## Simon Game

{{< cfimage src="images/simon-game.png" alt="A Simon game with four coloured quadrants and a step counter in the centre" caption="Simon Game" >}}

A replica of the [Simon](https://en.wikipedia.org/wiki/Simon_(game)) memory game.
You are shown a random series of button presses; each time you repeat one
correctly, the same series comes back with an additional step. Getting a series
of 20 steps right wins the game.

[Open the demo](https://codepen.io/gatezh/full/EmrxjY)
